🤖 Assistente de Escolha de Modelo de Machine Learning

Este projeto é um site interativo e responsivo desenvolvido para ajudar estudantes, profissionais e entusiastas da área de Machine Learning a descobrir qual modelo de ML é mais indicado para um determinado problema, com base em informações fornecidas de forma guiada.

🧠 Sobre o Projeto

A escolha do modelo ideal de Machine Learning pode ser desafiadora, especialmente para quem está começando. Este site funciona como uma espécie de assistente de decisão, onde o usuário vai clicando nas opções que melhor descrevem o seu problema (tipo de dado, objetivo, etc.) e, com isso, é guiado até a recomendação de um modelo adequado.

🔍 Exemplos de decisões guiadas:

Tipo de dado: Numérico, Categórico, Texto, Imagem...

Objetivo: Classificação, Regressão, Agrupamento...

Dados rotulados? Sim / Não

Quantidade de dados, complexidade, etc.

Ao final, o site sugere modelos como:

Regressão Linear / Logística

Decision Trees

Random Forest

KNN

SVM

Redes Neurais

K-Means

entre outros

🧰 Tecnologias Utilizadas

HTML5 – estrutura do site

CSS3 – layout responsivo, visual moderno

JavaScript (Vanilla) – lógica de interação e tomada de decisão

📱 Responsividade

O site foi desenvolvido com design responsivo, adaptando-se a diferentes tamanhos de tela (desktop, tablet e mobile), garantindo boa usabilidade em qualquer dispositivo.

⚙️ Como Funciona

O usuário acessa o site e responde perguntas simples, clicando nas opções.

A cada resposta, o sistema guia o usuário para o próximo passo, filtrando possibilidades.

Ao final, o modelo de ML mais adequado é sugerido, com uma breve explicação.

🧪 Casos de Uso

Alunos e alunas iniciantes em Machine Learning

Profissionais que desejam uma visão rápida das alternativas para um novo projeto

Aulas e treinamentos introdutórios em Ciência de Dados
